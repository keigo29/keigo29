## 🎯 モチベーション・目標

学生時代に日雇いアプリを通じて体験した「非効率な労働現場」や「情報格差」に衝撃を受け、  
**“誰もがストレスなく働ける環境”をITで実現すること** を目指しています。

- 技術力 × 顧客視点 を活かした開発
- 見た目も中身も心地よいWeb体験の提供
- フロントエンドだけでなく、**フルスタックへの進化** も視野に入れています
